========================================================================
        MIDAS M32  --  AUTO FX MUTE  (ઓટોમેશન સિસ્ટમ)
========================================================================

શું કરે છે?
-----------
માઈકમાં અવાજ આવે              ->  Mute Group 5 આપોઆપ UNMUTE (ઇફેક્ટ ચાલુ)
ગાવાનું બંધ થાય               ->  ૧.૫ સેકન્ડ પછી Mute Group 5 MUTE (ઇફેક્ટ બંધ)

એક કરતાં વધારે માઈક પણ રાખી શકાય (દા.ત. સિંગર + તબલા + વાંસળી).
   કોઈ પણ એક માઈકમાં અવાજ આવે   ->  ઇફેક્ટ ચાલુ
   બધા જ માઈક શાંત થાય          ->  ઇફેક્ટ બંધ

તમારા ડેસ્ક પર ચકાસાયેલું:
   Mute Group 5  =  Fx 1L, Fx 1R, Fx 4L, Fx 4R  (Reverb + Delay returns)
   /config/mute/5 = 1  ->  MUTE  (ઇફેક્ટ બંધ)
   /config/mute/5 = 0  ->  UNMUTE (ઇફેક્ટ ચાલુ)

એટલે પાછળથી અવાજ ગુંજતો નથી અને વ્હીસલ (feedback) વાગતી નથી.
સાઉન્ડ એન્જિનિયરે હાથથી મ્યુટ-અનમ્યુટ કરવું પડતું નથી.

        * નીચે       : Sensitivity, Hold, Attack ના સ્લાઈડર
        * ▶ CHALU KARO દબાવો એટલે automation શરૂ

      GUI ખોલો એટલે તરત મીટર દેખાય, પણ CHALU KARO દબાવો ત્યાં સુધી
      મિક્સર પર કંઈ જ થતું નથી -- એટલે લાઈવ વખતે પણ સલામત.

  6-GUI-PRACTICE-NO-MIXER.bat
      મિક્સર વગર GUI ની પ્રેક્ટિસ કરવા (નકલી મિક્સર સાથે).

  ---- નીચેની ફાઈલો CMD વાળી છે, જૂની રીત (હજી ચાલે છે) ----

  1-FIND-MIXER.bat
      નેટવર્કમાં મિક્સર શોધે છે અને તેનું IP આપોઆપ સેવ કરે છે.
      (તમારું મિક્સર: M32-0A-8D-19  @  192.168.45.100, FW 4.13
       -- પહેલેથી સેવ થઈ ગયું છે, ફરી કરવાની જરૂર નથી)

  2-CHANNEL-SELECT.bat        <<< જાતે પસંદ કરવા માટે (સહેલું)

      અત્યારે કઈ ચેનલમાં અવાજ આવે છે તે પણ (* નિશાની):

         1,5,9      =  ચેનલ ૧, ૫ અને ૯

========================================================================
૪. SETTINGS બદલવી હોય તો -- config.json ફાઈલ Notepad માં ખોલો
========================================================================

  "mixer_ip"      મિક્સરનું IP  (1-FIND-MIXER.bat આપોઆપ ભરે છે)

  "meter_index"   કઈ ચેનલ સાંભળવી.  index 0 = ચેનલ ૧, 1 = ચેનલ ૨, ...
                  (એટલે કે હંમેશા ચેનલ નંબર કરતાં એક ઓછું)

                  એક જ ચેનલ:        "meter_index": 0
                  ઘણી ચેનલ:         "meter_index": [0, 1, 4]
                                     (= ચેનલ ૧, ૨ અને ૫)

                  ઘણી ચેનલ હોય ત્યારે: કોઈ પણ એકમાં અવાજ આવે
                  તો ઇફેક્ટ ચાલુ, બધી શાંત થાય તો બંધ.

                  2-CHANNEL-SELECT.bat આ આપોઆપ ભરે છે (ત્યાં તમે
                  ચેનલ નંબર લખો છો, index નહીં). હાથે પણ લખી શકાય.

                  CMD માંથી સીધું સેટ કરવું હોય તો:
                     python channel_select.py 1,5,9
                  ટેસ્ટ કરવું હોય તો (સેવ કર્યા વગર):
                     python m32_automation.py --index 0,4,8

  "threshold_db"  કેટલા અવાજે ચાલુ થાય.
                  -40 = સામાન્ય.  વધારે વહેલું ચાલુ કરવું હોય -> -45, -50
                  ધીમો અવાજ પકડવો ના હોય   -> -35, -30

  "hold_time"     ગાવાનું બંધ થયા પછી કેટલી સેકન્ડ FX ચાલુ રાખવો.
                  1.5 = સામાન્ય.  લાંબો reverb હોય તો 2.5 કરો.

  "attack_time"   અવાજ આવ્યા પછી કેટલી વાર પછી ચાલુ કરવું (0.02 સેકન્ડ).
                  ખાંસી/ખખડાટ થી ચાલુ થઈ જતું હોય તો 0.1 કરો.

  "fx_targets"    શું મ્યુટ કરવું. અહીં એક કરતાં વધારે લખી શકાય:

      "/config/mute/5"                            = Mute Group 5  <-- અત્યારે આ
      "/config/mute/1" ... "/config/mute/6"       = બીજા mute group
      "/fxrtn/01/mix/on"  +  "/fxrtn/02/mix/on"   = FX 1 return (stereo)
      "/fxrtn/07/mix/on"  +  "/fxrtn/08/mix/on"   = FX 4 return (stereo)
      "/ch/01/mix/06/on"                          = ચેનલ ૧ નો FX-1 send
      "/bus/07/mix/on"                            = FX send bus 7

      બીજું mute group વાપરવું હોય તો ફક્ત આંકડો બદલો:
         "fx_targets": [ "/config/mute/3" ]

  "invert"        "auto" રહેવા દો.
                  mute group માં 1 = મ્યુટ, પણ channel માં 1 = ચાલુ --
                  "auto" આ ફરક જાતે સંભાળી લે છે.
                  જો ઊંધું થાય (બોલો ત્યારે બંધ, ચૂપ રહો ત્યારે ચાલુ)
                  તો "auto" ને બદલે true અથવા false લખો.

  "start_muted"   શરૂઆતમાં FX મ્યુટ કરી દેવો? (true = હા, સલામત)
  "mute_on_exit"  પ્રોગ્રામ બંધ કરતી વખતે મ્યુટ કરવો? (true = હા)
  "show_meter"    સ્ક્રીન પર લેવલ બાર બતાવવો? (true / false)

  ** ફાઈલ સેવ કર્યા પછી 4-RUN-AUTOMATION.bat ફરી ચાલુ કરવો. **

"Mixer e jawab na aapyo"

   -> LAN કેબલ ચેક કરો
   -> મિક્સર પર: Setup -> Network માં IP જુઓ
   -> Windows Firewall માં Python ને allow કરો

"Mixer parthi meter data band thai gayo"
   -> કેબલ ઢીલો છે અથવા network તૂટ્યું છે.
      પ્રોગ્રામ જાતે ફરી કનેક્ટ કરવાની કોશિશ કરે છે.

ટેસ્ટ કરવો હોય પણ ડેસ્ક પર કંઈ બદલવું ના હોય
   -> CMD માં:  python m32_automation.py --dry-run
      આ મિક્સરને એક પણ કમાન્ડ મોકલતું નથી, ફક્ત સ્ક્રીન પર બતાવે છે.

3-TEST-FX.bat ચલાવ્યે મિક્સર પર કંઈ ના બદલાય
   -> config.json માં "fx_targets" ખોટા છે. ઉપર ભાગ ૪ માંથી
      બીજો option લખી જુઓ. અથવા સીધું ટેસ્ટ કરો:
         python test_fx.py /fxrtn/03/mix/on

FX વારંવાર ચાલુ-બંધ થયા કરે (flicker)
   -> "hold_time" વધારો (2.0 કે 2.5)

તાળી/ખાંસી થી પણ ચાલુ થઈ જાય
   -> "threshold_db" ઊંચું કરો (-40 ને બદલે -32)
   -> "attack_time" 0.1 કરો
