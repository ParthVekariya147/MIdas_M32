     તમારા સવાલોના સીધા જવાબ

સવાલ ૧ : આ પ્રોગ્રામ સીધો મિડાસ M32 ની અંદર નાખી દઉં તો ચાલે?
         પેન ડ્રાઈવ ચડાવી દઉં તો? કોઈ plugin બનાવી શકાય?
------------------------------------------------------------------------

જવાબ : ના. આ ત્રણેમાંથી એકેય રીતે ના ચાલે.

કારણ :

 ૧. M32 ની અંદર એક નાનું બંધ (locked) કમ્પ્યુટર છે. તેમાં Behringer/Midas
    નું પોતાનું firmware ચાલે છે. તેમાં કોઈ બહારનો પ્રોગ્રામ install
    કરવાની સગવડ જ નથી -- ના Python, ના .exe, ના script.

 ૨. મિક્સરનું USB પોર્ટ ફક્ત ત્રણ કામ માટે છે:
       - WAV ફાઈલનું recording / playback
       - Scene / Show ફાઈલ save-load
       - Firmware update (.update ફાઈલ)
    તેમાં પ્રોગ્રામ મૂકશો તો મિક્સર તેને ઓળખશે જ નહીં -- કંઈ થશે નહીં.
    (મિક્સરને નુકસાન નહીં થાય, પણ ચાલશે પણ નહીં.)

 ૩. M32 માં plugin/app store જેવું કંઈ છે જ નહીં. Behringer એ
    plugin બનાવવાની કોઈ સગવડ (SDK) જાહેર કરી નથી.

 ૪. મિક્સરમાં જે "automation" છે તે ફક્ત આટલું જ:
       - Scene / Snippet  (બટન દબાવો ત્યારે સેટિંગ બદલાય)
       - Auto Mix         (ફક્ત fader નું level, mute નહીં)
       - USB / MIDI remote
    "અવાજ સાંભળીને આપોઆપ mute-unmute" -- એવું મિક્સરમાં છે જ નહીં.
    એટલા માટે જ બહાર કમ્પ્યુટર જોઈએ.

એટલે : આ કામ કરવા માટે **બહાર કોઈક ડબ્બો ચાલુ રહેવો જ પડશે.**
        બીજો કોઈ રસ્તો છે નહીં.


========================================================================
સવાલ ૨ : PC ચાલુ ના હોય તો? ત્યારે ઇફેક્ટ વાળું નહીં ચાલે ને?
========================================================================

જવાબ : સાચી વાત. PC બંધ = automation બંધ.

પણ ગભરાવાની જરૂર નથી :

 * PC બંધ થાય તો મિક્સર **જેમ છે તેમ જ ચાલુ રહે છે**. અવાજ બંધ નહીં થાય.
   ફક્ત automation અટકી જશે -- એટલે mute-unmute હાથે કરવું પડશે,
   જેમ પહેલા કરતા હતા તેમ.

 * મિક્સર પર તમે ગમે ત્યારે હાથે Mute Group દબાવી શકો છો.
   પ્રોગ્રામ ચાલુ હોય તો પણ, બંધ હોય તો પણ.

 * પ્રોગ્રામ બરાબર બંધ થાય (Ctrl+C / GUI બંધ) ત્યારે એ છેલ્લે
   ઇફેક્ટ MUTE કરી દે છે -- એટલે અચાનક ગુંજારવ ના થાય.


ડબ્બા માટે ૩ ઓપ્શન -- તમારે જે ફાવે તે :

 A) જૂનું લેપટોપ / PC             ખર્ચ : ૦ (પડ્યું હોય તો)
    ------------------------------------------------------------
    * અત્યારે આ જ કરો. જે છે તે ચલાવો.
    * ઢાંકણ બંધ કરો તો પણ ચાલુ રહે તેવું સેટ કરો:
        Control Panel -> Power Options ->
        "Choose what closing the lid does" -> "Do nothing"
    * Sleep બંધ કરો: Settings -> Power -> Screen and sleep ->
        "Never" કરો.
    * README ના ભાગ ૬ પ્રમાણે startup માં મૂકો -- PC ચાલુ થતાં જ
      automation ચાલુ.
    ફાયદો  : અત્યારે જ મફતમાં થઈ જાય
    નુકસાન : મોટું, વીજળી વધારે, દર વખતે ચાલુ કરવું પડે


 B) Raspberry Pi              ખર્ચ : આશરે રૂ. ૪,૦૦૦ - ૬,૦૦૦   << ભલામણ
    ------------------------------------------------------------
    * હાથમાં સમાય તેવું નાનું કમ્પ્યુટર. Rack માં કે મિક્સર પાછળ
      ટેપથી ચોંટાડી શકાય.
    * વીજળી ફક્ત ૩-૫ વોટ (મોબાઈલ ચાર્જર જેટલી).
    * એક જ વાર સેટ કરો -- પછી પાવર આપો એટલે ૩૦ સેકન્ડમાં
      automation જાતે ચાલુ. સ્ક્રીન-કીબોર્ડ કંઈ જોઈએ નહીં.
    * આ જ Python કોડ ત્યાં જેમનો તેમ ચાલશે -- એક પણ લીટી બદલવાની નથી
      (Python બધે સરખું ચાલે છે).
    * જોઈએ : Raspberry Pi 4 / 5 (કે Pi Zero 2W પણ ચાલે),
             SD card, પાવર એડેપ્ટર, LAN કેબલ.
    ફાયદો  : હંમેશા ચાલુ, નાનું, સસ્તું ચલાવવામાં, ભરોસાપાત્ર
    નુકસાન : એક વાર સેટ કરવું પડે (હું સ્ટેપ લખી આપીશ)


 C) Mini PC (Intel NUC જેવું)   ખર્ચ : આશરે રૂ. ૧૨,૦૦૦ +
    ------------------------------------------------------------
    * નાનું Windows કમ્પ્યુટર. બધું આજની જેમ જ ચાલે, GUI પણ.
    ફાયદો  : Windows જ છે, કંઈ નવું શીખવાનું નહીં, GUI ચાલે
    નુકસાન : મોંઘું, વીજળી વધારે


મારી સલાહ : અત્યારે (A) જૂના લેપટોપથી ચલાવો અને બરાબર વાપરી જુઓ.
             બે-ચાર પ્રોગ્રામ પછી બરાબર લાગે તો (B) Raspberry Pi
             લઈ લેજો -- એ પછી કાયમી ઉકેલ થઈ જશે.


========================================================================
સવાલ ૩ : આગળ જતાં requirement બદલાય તો? ગ્રુપ નહીં પણ કોઈ એક
          ચેનલ, કે બીજું કંઈ કરવું હોય તો?
========================================================================

જવાબ : એના માટે જ હવે UNIVERSAL બનાવી દીધું છે.

GUI માં જમણી બાજુ "Prakaar (type)" નું ડ્રોપડાઉન છે. તેમાંથી કંઈ પણ
પસંદ કરી શકાય -- કુલ ૮૬ વસ્તુ :

    Mute Group  1-6         (અત્યારે આ વાપરીએ છીએ)
    FX Return   1-8
    Channel     1-32        (કોઈ પણ એક ચેનલ mute/unmute)
    Bus         1-16
    Matrix      1-6
    DCA         1-8
    Aux In      1-8
    Main LR  /  Main Mono

એક કરતાં વધારે પણ ભેગા પસંદ કરી શકાય. દા.ત. Mute Group 5 કાઢી નાખો
અને Channel 9 + Channel 10 ઉમેરી દો -- થઈ ગયું, બીજું કંઈ બદલવાનું નહીં.

આ યાદીમાં ના હોય એવું કંઈક જોઈએ તો નીચે "Custom OSC" ખાનું છે --
તેમાં સીધો path લખી શકાય. દા.ત.
    /ch/01/mix/06/on        (ચેનલ ૧ નો FX-1 send)
    /ch/05/mix/fader        (fader નું level)

પ્રોગ્રામ જાતે સમજી લે છે કે કઈ વસ્તુમાં 1 એટલે ચાલુ અને કઈમાં
1 એટલે બંધ (mute group માં ઊંધું હોય છે) -- તમારે વિચારવાનું નહીં.


========================================================================
સવાલ ૪ : CMD ને બદલે સ્ક્રીન વાળું (front-end) જોઈએ
========================================================================

જવાબ : બની ગયું.  ->  0-START-GUI.bat  પર ડબલ-ક્લિક

તેમાં શું દેખાશે:

  ઉપર      : Mixer IP + "Judo" + "Network ma shodho" બટન
              લીલી ટપકી = જોડાયેલું, લાલ = નથી જોડાયેલું

  ડાબી બાજુ : બધી ૩૨ ચેનલ -- નામ સાથે, અને દરેકનું LIVE મીટર
              જે માઈક સાંભળવા હોય તેના પર ✔ ટિક કરો
              (સફેદ લીટી = threshold ક્યાં છે તે બતાવે)

  જમણી બાજુ : શું ચાલુ/બંધ કરવું -- ડ્રોપડાઉનમાંથી પસંદ કરી
              "UMERO" દબાવો. TEST બટનથી ૩ વાર on/off કરીને ચકાસો.

  નીચે      : Sensitivity, Hold time, Attack ના સ્લાઈડર
              (ચાલુ હોય ત્યારે પણ ખસેડી શકાય -- તરત અસર થાય)

  છેલ્લે    : ▶ CHALU KARO બટન, અને નીચે લોગ

  મહત્વનું : GUI ખોલો એટલે તરત મીટર દેખાવા લાગશે, પણ
             "CHALU KARO" દબાવો ત્યાં સુધી મિક્સર પર **કંઈ જ નહીં થાય**.
             એટલે લાઈવ પ્રોગ્રામ વખતે પણ સલામત રીતે ખોલી શકાય.

  "SAVE settings" દબાવો એટલે config.json માં સેવ થાય -- પછી
  CMD વાળો પ્રોગ્રામ (4-RUN-AUTOMATION.bat) પણ એ જ સેટિંગ વાપરશે.


પ્રેક્ટિસ કરવી હોય તો : 6-GUI-PRACTICE-NO-MIXER.bat
   મિક્સર વગર, નકલી મિક્સર સાથે GUI ચલાવીને શીખી શકાય.
