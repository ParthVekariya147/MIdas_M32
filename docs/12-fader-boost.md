# 12 — Fader જાતે 0 dB પર (અને પાછું જ્યાં હતું ત્યાં)

## શું કરે છે

> મ્યુટ ગ્રુપ **અનમ્યુટ** થાય → ઇફેક્ટનો fader (દા.ત. **DCA 8**) **0 dB** પર
> પાછું **મ્યુટ** થાય → fader **જ્યાં હતો ત્યાં** પાછો

```
   fader -20 dB
        │
        ├─ અનમ્યુટ થયું  →  fader   0 dB     (જૂનું -20 યાદ રાખ્યું)
        │
        └─ મ્યુટ થયું    →  fader -20 dB     (પાછું ત્યાં જ)
```

## લોજિક

| ક્યારે | શું કરે |
|---|---|
| **અનમ્યુટ** | ચકાસે કે fader `to_db` (0 dB) ઉપર છે કે નહીં.<br>**ના હોય તો** — અત્યારનું value યાદ રાખે, પછી 0 dB પર લઈ જાય |
| **મ્યુટ** | યાદ રાખેલા value પર પાછો લઈ જાય |

`ramp_ms` (250 ms) માં **ધીમે ધીમે** જાય — એકદમ કૂદકો મારે તો click સંભળાય.

## સેટિંગ્સ (Tab 1, નીચે)

| નામ | default | શું કરે |
|---|---|---|
| `target` | `/dca/8/fader` | **કયો fader** — DCA 1-8 કે કોઈ પણ ચેનલ. ડ્રોપડાઉનમાંથી બદલો |
| `to_db` | 0.0 | ક્યાં સુધી લઈ જવો |
| `tolerance_db` | 1.0 | આટલાની અંદર હોય તો **હાથ જ ના લગાવે** |
| `ramp_ms` | 250 | કેટલી વારમાં (0 = તરત) |

Toggle: **`fader_boost`** — default **બંધ**.

## ⭐ ત્રણ સલામતી

### ૧. પહેલેથી બરાબર હોય તો કંઈ જ ના કરે
fader પહેલેથી 0 dB (±`tolerance_db`) પર હોય તો અડે જ નહીં —
અને એટલે મ્યુટ થાય ત્યારે પણ કંઈ પાછું ના લઈ જાય.

### ૨. એન્જિનિયર હાથથી બદલે તો લડે નહીં
અનમ્યુટ પછી તમે જાતે fader ખસેડો → મ્યુટ થાય ત્યારે પ્રોગ્રામ
**પાછો નથી લઈ જતો**. log માં લખાય:
```
Fader: /dca/8/fader hathe badlayo -- pachho nathi lai jato
```

### ૩. Safe Mode
`safe_mode` ચાલુ હોય તો એક પણ કમાન્ડ જાય જ નહીં.

## કોડ ક્યાં છે

| શું | ફાઈલ |
|---|---|
| મુખ્ય લોજિક | `m32_engine.py` → `_fader_boost()` |
| ધીમે ધીમે ખસેડવું | `m32_engine.py` → `_ramp()`, `_run_ramps()` |
| dB → fader value | `m32_core.py` → `db_to_fader()` |
| fader value → dB | `m32_core.py` → `fader_to_db()` |
| સેટિંગ્સ | `m32_core.py` → `FADER_BOOST_DEFAULTS` |
| UI | `m32_gui.py` → `_build_features()` ના છેડે |

## ⚠️ પકડાયેલો બગ (યાદ રાખવા જેવો)

**લક્ષણ:** fader 0 dB પર જતો, પણ મ્યુટ થાય ત્યારે **પાછો ના આવતો**.
log માં ખોટું લખાતું: *"hathe badlayo"*.

**કારણ:** આપણે 0.75 મોકલ્યું, પણ `self.dca_fader` માં હજી જૂનું 0.375
પડ્યું હતું (મિક્સર જવાબ આપે ત્યારે જ એ ભરાય છે). એટલે "એન્જિનિયરે
બદલ્યું" એવો ખોટો ગાર્ડ લાગી જતો.

**ફિક્સ:** `_note_fader()` — આપણે જે મોકલીએ તે **આપણી યાદીમાં પણ** લખવું.

```python
self.mixer.send(path, val)
self._note_fader(path, val)     # આ લીટી ખૂટતી હતી
```
