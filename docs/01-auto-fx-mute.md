# 01 — Auto FX Mute (મુખ્ય ફીચર)

## શું કરે છે

પસંદ કરેલા માઈકમાં અવાજ આવે → target **ચાલુ** (unmute)
બધા માઈક શાંત થાય → hold time પછી target **બંધ** (mute)

## લોજિક (સાદી ભાષામાં)

```
દર 50 વાર/સેકન્ડ:
    level = પસંદ કરેલી બધી ચેનલમાંથી સૌથી મોટો અવાજ (dB માં)

    જો level > threshold:
        છેલ્લો_અવાજ_ટાઈમ = અત્યારે
        જો હજી બંધ છે અને attack સેકન્ડ વીતી ગઈ:
            → ચાલુ કરો
    નહીં તો:
        જો ચાલુ છે અને (અત્યારે - છેલ્લો_અવાજ_ટાઈમ) > hold:
            → બંધ કરો
```

## કોડ ક્યાં છે

| શું | ફાઈલ | જગ્યા |
|---|---|---|
| નિર્ણય લેવાનું | `m32_engine.py` | `Engine._update()` |
| કમાન્ડ મોકલવાનું | `m32_engine.py` | `Engine._apply()` |
| મુખ્ય લૂપ | `m32_engine.py` | `Engine.run()` |
| dB ગણતરી | `m32_core.py` | `to_db()` |

## સેટિંગ્સ

| નામ | default | શું કરે |
|---|---|---|
| `threshold_db` | -40 | આનાથી ઊંચો અવાજ = "ગાય છે". ઓછું (-50) = વધારે sensitive |
| `hold_time` | 1.5 s | બંધ થયા પછી કેટલી વાર ચાલુ રાખવું |
| `attack_time` | 0.02 s | અવાજ આવ્યા પછી કેટલી વાર પછી ચાલુ કરવું |

## Toggle જે આને અસર કરે છે

| toggle | ચાલુ | બંધ |
|---|---|---|
| `auto_fx` | જાતે ચાલુ/બંધ થાય | કંઈ જાતે ના બદલાય (મીટર દેખાય) |
| `safe_mode` | — | મિક્સર પર ખરેખર કમાન્ડ જાય |
| `start_muted` | શરૂઆતમાં બંધ કરી દે | જેમ છે તેમ રહેવા દે |
| `mute_on_exit` | બંધ કરતાં mute કરે | જેમ છે તેમ છોડી દે |
| `respect_fader` | fader/mute ધ્યાનમાં લે ([docs/10](10-fader-aware.md)) | ફક્ત મીટર જુએ |

## લાઈવ પ્રોગ્રામમાં સલામતી

1. GUI ખોલો → મીટર દેખાય, **મિક્સર પર કંઈ ના થાય**
2. મોટું toggle ચાલુ કરો → ત્યારે જ કમાન્ડ જાય
3. એન્જિનિયર ગમે ત્યારે મિક્સર પર હાથથી બદલી શકે
4. PC બંધ થાય → મિક્સર જેમ છે તેમ ચાલુ રહે, ફક્ત automation અટકે

## શું બગડી શકે

| લક્ષણ | કારણ | ઉપાય |
|---|---|---|
| વારંવાર ચાલુ-બંધ (flicker) | hold time ઓછો | `hold_time` વધારો (2.0-2.5) |
| ખાંસી/તાળીથી ચાલુ થાય | threshold નીચો | `threshold_db` ઊંચો (-32) અથવા `attack_time` 0.1 |
| ધીમું ગાય તો પકડાય નહીં | threshold ઊંચો | `threshold_db` નીચો (-48) |
| ઊંધું થાય (બોલો તો બંધ) | invert ખોટું | `config.json` માં `"invert"` ને `true`/`false` |
| કંઈ જ ના થાય | target ખોટો કે toggle બંધ | docs/03 અને docs/09 વાંચો |
