# 02 — કઈ ચેનલ સાંભળવી

## શું કરે છે

એક કે વધારે માઈક પસંદ કરી શકાય.
**કોઈ પણ એકમાં** અવાજ આવે → ઇફેક્ટ ચાલુ. **બધા** શાંત → બંધ.

## ⚠️ index vs ચેનલ નંબર

કોડમાં **index** વપરાય છે, જે ચેનલ નંબર કરતાં **એક ઓછો** હોય છે.

| ચેનલ | index |
|---|---|
| CH 1 | 0 |
| CH 5 | 4 |
| CH 9 | 8 |

GUI અને `select` ટૂલમાં તમે **ચેનલ નંબર** લખો છો — એ જાતે index માં ફેરવે છે.
`config.json` માં **index** લખેલો હોય છે.

## પસંદ કરવાની ૩ રીત

### ૧. GUI (સૌથી સહેલી)
ડાબી બાજુ દરેક ચેનલનું toggle છે. ચાલુ કરો એટલે એ માઈક સંભળાશે.

### ૨. જાતે લખીને
```
M32-AutoFX.exe select 1,5,9      → CH 1, 5, 9
M32-AutoFX.exe select 1-4        → CH 1 થી 4
M32-AutoFX.exe select 1-4,9,12   → ભેગું
```

### ૩. આપોઆપ શોધવું
```
M32-AutoFX.exe scan
```
પહેલા શાંત રહો (4 સેકન્ડ), પછી માઈકમાં બોલો (6 સેકન્ડ).
શાંતિ અને અવાજ સરખાવીને જાતે નક્કી કરે છે, અને threshold પણ ગોઠવી આપે છે.

## કોડ ક્યાં છે

| શું | ફાઈલ |
|---|---|
| index સમજવું (`"0,1,4"` → `[0,1,4]`) | `m32_core.py` → `parse_indexes()` |
| સૌથી મોટો અવાજ શોધવો | `m32_engine.py` → `_on_packet()` |
| GUI ના toggle | `m32_gui.py` → `_build_channels()` |
| જાતે પસંદ કરવાનું ટૂલ | `channel_select.py` |
| આપોઆપ શોધવાનું ટૂલ | `meter_scan.py` |

## Meter bank શું છે

M32 મીટર ડેટા "bank" માં મોકલે છે. તમારા મિક્સર પર:

| bank | કેટલી value | શું |
|---|---|---|
| **0** | 70 | પહેલી 32 = ચેનલ 1-32 ← **આ વાપરીએ છીએ** |
| 1 | 96 | |
| 2 | 49 | |
| 3 | 22 | |
| 4 | 82 | |
| 5 | 27 | |
| 6 | 4 | |

**bank 0 (pre-fader) કેમ:** fader નીચો હોય તો પણ માઈકનો અવાજ દેખાય.

## ⚠️ પકડાયેલો બગ — યાદ રાખવા જેવો

M32 એકસાથે **એક કરતાં વધારે bank** મોકલી શકે છે. જવાબનું address
બરાબર મેચ ના કરીએ તો ખોટી ચેનલ વંચાય.

```python
if address != self._meter_address:    # "/meters/0"
    return
```

એ જ રીતે `scan` હવે **ફક્ત index 0-31** માંથી પસંદ કરે છે — નહીં તો
એક વાર index 50 (જે bus છે) પસંદ થઈ ગયો હતો.

## શું બગડી શકે

| લક્ષણ | ઉપાય |
|---|---|
| ખોટી ચેનલ પકડાય | GUI માં મીટર જુઓ — બોલો ત્યારે કઈ ચેનલ હલે છે |
| scan ખોટો જવાબ આપે | માઈકનો gain વધારો, વધારે મોટેથી બોલો, ફરી scan |
| બધી ચેનલ -95 dB | માઈક ચેનલ પર છે? gain છે? bank સાચો છે? |
