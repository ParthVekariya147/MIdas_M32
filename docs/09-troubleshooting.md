# 09 — પ્રોબ્લેમ આવે તો

## પહેલા આ ૩ કરો

```
1.  M32-AutoFX.exe test      ← ૬૩ ટેસ્ટ. બધા PASS થાય છે?
2.  M32-AutoFX.exe gui --sim ← નકલી મિક્સરથી ચાલે છે?
3.  automation.log વાંચો     ← છેલ્લે શું થયું?
```

**ટેસ્ટ PASS થાય પણ સાચા મિક્સર પર ના ચાલે** → નેટવર્ક/OSC path નો પ્રશ્ન
**ટેસ્ટ FAIL થાય** → કોડનો પ્રશ્ન, નીચે જુઓ કયો ટેસ્ટ ફેલ થયો

---

## જોડાણના પ્રશ્નો

### "Mixer jawab nathi aapto"
1. GUI માં **"Network ma shodho"** દબાવો — જાતે શોધી કાઢશે
2. LAN કેબલ મિક્સરના **REMOTE** પોર્ટમાં છે?
3. મિક્સર પર: **Setup → Network** માં IP જુઓ
4. PC અને મિક્સર **એક જ subnet** માં છે?
   દા.ત. મિક્સર `192.168.45.100` → PC `192.168.45.x` હોવું જોઈએ
   ```
   ipconfig            (PC નું IP જુઓ)
   ping 192.168.45.100
   ```
5. **Windows Firewall** માં exe ને allow કરો

### "Mixer parthi data band thai gayo"
- કેબલ ઢીલો કે નેટવર્ક તૂટ્યું
- `auto_reconnect` toggle ચાલુ હોય તો જાતે ફરી જોડાશે
- વારંવાર થાય → કેબલ/switch બદલો

## Automation ના પ્રશ્નો

### કંઈ જ થતું નથી
ક્રમમાં ચકાસો:

| # | ચકાસો | કેવી રીતે |
|---|---|---|
| 1 | મોટું toggle ચાલુ છે? | નીચે લીલું દેખાવું જોઈએ |
| 2 | `safe_mode` બંધ છે? | ચાલુ હોય તો કમાન્ડ જતા જ નથી |

### ઊંધું થાય — બોલો તો બંધ, ચૂપ રહો તો ચાલુ

### વારંવાર ચાલુ-બંધ (flicker)

## .exe ના પ્રશ્નો

| લક્ષણ | ઉપાય |
|---|---|
| Antivirus રોકે | "Allow"/"Keep" — PyInstaller સાથે સામાન્ય |
| ખૂલે પણ તરત બંધ | `M32-AutoFX.exe run` થી cmd માં ચલાવો |

| સેટિંગ્સ ના સચવાય | Program Files માં ના મૂકો (write permission) |

## પહેલા પકડાયેલા બગ (ફરી થાય તો ઓળખાય)

### ૧. લેવલ ચેક દર ૩ સેકન્ડે થતું
**લક્ષણ:** ઇફેક્ટ મોડી ચાલુ થાય, ટાઈમિંગ ખોટું
**કારણ:** socket blocking હતું, drain loop ખાલી થતો જ નહીં
**ફિક્સ:** `sock.setblocking(False)` + `select()`
**ફાઈલ:** `m32_core.py` → `Mixer.__init__`, `wait()`

### ૨. ખોટી ચેનલ વંચાતી
**લક્ષણ:** બોલો બીજી ચેનલમાં, પકડાય ત્રીજી
**કારણ:** M32 એકસાથે ઘણા bank મોકલે, બધા સ્વીકારાતા
**ફિક્સ:** `if address != self._meter_address: return`
**ફાઈલ:** `m32_engine.py` → `_on_packet()`

### ૩. scan એ bus પસંદ કરી લીધો (index 50)
**લક્ષણ:** scan પછી કંઈ કામ ના કરે
**કારણ:** ચેનલ ઉપરાંત bus/aux ના મીટર પણ ગણાતા
**ફિક્સ:** `MAX_CHANNEL = 32` — ફક્ત ચેનલ 1-32
**ફાઈલ:** `meter_scan.py` → `rank()`

### ૪. exe માં સેટિંગ્સ ખોવાઈ જતી
**લક્ષણ:** SAVE કરો પણ પછી પાછું જૂનું
**કારણ:** `--onefile` માં `__file__` = temp ફોલ્ડર
**ફિક્સ:** `sys.executable` ની બાજુમાં લખવું
**ફાઈલ:** `m32_core.py` → `_base_folder()`
