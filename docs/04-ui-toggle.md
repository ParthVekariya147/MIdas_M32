# 04 — UI અને Toggle બટન

## નિયમ

> **બધું ચાલુ/બંધ toggle બટનથી જ થાય.** ચેકબોક્સ કે અલગ અલગ પ્રકારના
> બટન નહીં — બધે એક જ દેખાવ. UI સાદું રાખવું.

## ક્યાં ક્યાં toggle છે

| જગ્યા | કેટલા | શું ચાલુ/બંધ કરે |
|---|---|---|
| નીચે (મોટું) | 1 | આખું automation |
| ડાબે, દરેક ચેનલ | 32 | એ માઈક સાંભળવો કે નહીં |
| જમણે, દરેક target | જેટલા ઉમેર્યા | એ વસ્તુ કંટ્રોલ કરવી કે નહીં |
| નીચે, features | 6 | નીચેની યાદી |

## Feature toggle ની યાદી

| key | નામ | ચાલુ હોય તો | બંધ હોય તો |
|---|---|---|---|
| `safe_mode` | Safe Mode (test) | મિક્સરને **એક પણ કમાન્ડ ના જાય** | ખરેખર કમાન્ડ જાય |
| `start_muted` | શરૂઆતમાં mute | ચાલુ થતાં target બંધ કરે | જેમ છે તેમ |
| `mute_on_exit` | બંધ કરતાં mute | બંધ થતાં target બંધ કરે | જેમ છે તેમ |
| `auto_reconnect` | જાતે ફરી જોડો | નેટવર્ક તૂટે તો જાતે જોડાય | ફક્ત warning |
| `logging` | Log file લખો | automation.log માં સાચવે | ના સાચવે |
| `show_meter` | મીટર બતાવો | લેવલ બાર દેખાય | ના દેખાય (CPU ઓછું) |

`auto_fx` પણ feature છે, પણ એનું toggle નીચેનું **મોટું** toggle જ છે.

## નિયમો

1. **ચાલુ હાલતમાં પણ** toggle બદલી શકાય — તરત અસર, restart નહીં
2. બધા toggle `config.json` ના `features` માં સેવ થાય (SAVE દબાવો)
3. જૂની config પણ ચાલે (`start_muted` સીધું લખેલું હોય તો પણ)
4. `safe_mode` ચાલુ → **ગમે તે થાય, કમાન્ડ ના જાય**
5. મોટું toggle બંધ → મીટર દેખાય પણ મિક્સર પર કંઈ ના થાય

## કોડ ક્યાં છે

| શું | ફાઈલ |
|---|---|
| Toggle બટન બનાવવાનું | `m32_gui.py` → `class Toggle` |
| લેવલ મીટર | `m32_gui.py` → `class LevelBar` |
| Feature ની યાદી | `m32_core.py` → `FEATURES` |
| Feature વાંચવું | `m32_core.py` → `get_feature()` |
| Feature પાળવું | `m32_engine.py` → `feature()`, `set_feature()` |
| ચેનલ toggle | `m32_gui.py` → `_build_channels()` |
| Target toggle | `m32_gui.py` → `_refresh_targets()` |
| Feature toggle | `m32_gui.py` → `_build_features()` |
| મોટું toggle | `m32_gui.py` → `_build_bottom()`, `_run_toggled()` |

## નવું feature toggle ઉમેરવાની રીત

**૧.** `m32_core.py` માં `FEATURES` માં એક લીટી:
```python
"navu_feature": ("દેખાતું નામ", "શું કરે તેનું ટૂંકું વર્ણન", True),
```

**૨.** `m32_engine.py` માં જ્યાં જોઈએ ત્યાં:
```python
if self.feature("navu_feature"):
    ...
```

**૩.** બસ — GUI માં toggle **જાતે દેખાશે** (`FEATURES` માંથી બને છે).

**૪.** `test_all.py` માં ટેસ્ટ ઉમેરો, પછી `python m32_app.py test`

## Toggle કેમ બનાવ્યું છે (ટેકનિકલ)

Tkinter માં તૈયાર toggle નથી, એટલે `Canvas` પર દોરેલું છે:
- ટ્રેક = બે ગોળ + વચ્ચે લંબચોરસ
- knob = ગોળ, જે ડાબે-જમણે ખસે
- રંગ: ચાલુ = લીલો `#3fbf5f`, બંધ = કાળો `#3a3a3a`
- `tk.BooleanVar` સાથે જોડાયેલું, `trace_add` થી જાતે redraw

## શું બગડી શકે

| લક્ષણ | ઉપાય |
|---|---|
| Toggle દબાવો પણ કંઈ ના થાય | engine જોડાયું નથી? — "Judo" દબાવો |
| મોટું toggle પાછું બંધ થઈ જાય | કોઈ target પસંદ નથી — જમણેથી ઉમેરો |

| સેટિંગ્સ યાદ ના રહે | **SAVE settings** દબાવવું જરૂરી છે |
