========================================================================
૩. કઈ ફાઈલમાં શું છે
========================================================================

  osc_lite.py        મિક્સરની ભાષા (OSC). કંઈ install કરવાની જરૂર નહીં.
                     build_message() / parse_message() / decode_meter_blob()

  m32_core.py        પાયાની વસ્તુઓ:
                       Mixer         -- UDP socket, subscribe, send
                       to_db()       -- meter value -> dB
                       parse_indexes()-- "0,1,4" -> [0,1,4]
                       target_catalog() -- ૮૬ કંટ્રોલ કરી શકાય તેવી વસ્તુ
                       mute_value()  -- કઈ વસ્તુમાં 1 એટલે ચાલુ/બંધ
                       load_config() / save_config()

  m32_engine.py      *** આખું મગજ અહીં છે ***
                     Engine (thread) -- મીટર વાંચે, નિર્ણય લે, કમાન્ડ મોકલે
                       .set_active()  -- કમાન્ડ મોકલવા કે નહીં
                       .set_params()  -- ચાલુ હાલતમાં સેટિંગ બદલો
                       .snapshot()    -- અત્યારની હાલત

                     GUI અને CMD બન્ને આ જ વાપરે છે.
                     નવું feature આમાં ઉમેરો -> બન્નેમાં આવી જશે.

  m32_gui.py         સ્ક્રીન વાળો પ્રોગ્રામ (Tkinter)
  m32_automation.py  CMD વાળો પ્રોગ્રામ
  m32_simulator.py   નકલી M32
  test_all.py        ૪૫ આપોઆપ ટેસ્ટ

  channel_select.py  ચેનલ જાતે પસંદ કરવાનું (CMD)
  meter_scan.py      બોલો એટલે ચેનલ જાતે શોધે (CMD)
  find_mixer.py      નેટવર્કમાં મિક્સર શોધે
  test_fx.py         ૩ વાર on/off કરીને ચકાસે

    ૨. test_all.py માં તેનો ટેસ્ટ ઉમેરો
    ૩. બન્ને (GUI + CMD) માં આપોઆપ આવી જશે

========================================================================
૫. મિક્સર વગર શું ના થાય
========================================================================

  ૯૫% બધું નકલી મિક્સરથી થઈ જાય. ફક્ત આટલું સાચા ડેસ્ક પર
  ચકાસવું પડે (અને એ પહેલા ચકાસી લીધું છે):

   * OSC path સાચા છે કે નહીં
     -- /config/mute/5 અને /fxrtn/xx/mix/on ચકાસાઈ ગયા છે ✔
     -- નવો path ઉમેરો તો ડેસ્ક પર એક વાર ચકાસવો

   * મીટર bank માં કઈ index એ કઈ ચેનલ
     -- તમારા M32 પર: bank 0 = ૭૦ value, પહેલી ૩૨ = ચેનલ ૧-૩૨ ✔

   * ખરેખરા માઈકનો અવાજ કેટલા dB આવે (threshold નક્કી કરવા)
     -- એ 2B-AUTO-SCAN.bat જાતે ગોઠવી આપશે
